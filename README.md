The NPS Explorer allows users to explore and interact with national park information.

The home page provides an overview of what users can do, including browsing national parks by state in alphabetical order, accessing a personalized trip planner, and tracking their progress. It also features park videos to create a more engaging experience.

By selecting a state, users can view detailed information about the national parks located there. Users can add parks to their personalized trip planner and track their progress as they visit them.
